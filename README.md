# Northwind_Traders_SQL_Analysis
### Northwind Traders: A Strategic Business Analysis

##### Project Summary:
In the project I evaluate employee performance, evaluate product sales and category performance, analyze sales growth, and evaluate customer purchase behavior using SQL. 

#### Disclaimer:
This project is a guided analysis from the platform [dataquest.io](http://dataquest.io). Most of the code, all of the markdown cells, and every analysis interpretation is my own work. The guided projects provide structure on what steps to take for successful project completion. For more information about what projects dataquest.io offers and how they are structured, visit their page using [this link](https://www.dataquest.io/data-science-projects/). 
 
#### Key Findings:
1. Margaret Peacock, Janet Leverling, and Nancy Davolio are the top 3 sales performers.
2. Sales start strong with an all time high in the first month of every year and tend to fluctuate throughout the year ending strong in December.
3. The months that sales tend to decrease and the months that sales are historically higher.
4. A table that lists every customer and whether their order was above average.
5. Beverages (21%) make up the most sales out of all the categories with Dairy Products (18%) as a close second
6. A table that lists the top 3 performing products for each category.

#### Datasource:
The project uses the Northwind sample database, which originates from Microsoft. You can find the sample used in the dataquest.io project [here](https://github.com/pthom/northwind_psql). A downloadable version from Microsoft can be found [here](https://github.com/Microsoft/sql-server-samples/tree/master/samples/databases/northwind-pubs).

#### SQL Skills Used:
The SQL techniques I used in this project: joins, aggregations, CTEs, window functions, subqueries, and CASE statements. 

#### Tools Used:
This project uses JupyterLab, PostgreSQL, and the Python libraries ipython-sql and python-dotenv.
